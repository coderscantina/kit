# Agent notes

The conventions for this repository are in [CLAUDE.md](CLAUDE.md): where feature code goes, the reactive contract (always generate queries and mutations, never hand-roll transactions, `afterCommit`, invalidation or authorization), the frontend contract (data only through `useReactiveQuery`/`useReactiveMutation`, explicit composable imports, regenerate types after any data-class change), what "done" means, how a release is cut, and a list of accepted trade-offs that are deliberate and should not be filed as findings. Read it before changing anything, and run `bin/gate` before you call the work finished.
